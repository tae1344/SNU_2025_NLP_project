# 🏢 삼성전자 재무 분석 시스템

Enhanced Knowledge Graph 기반 재무 분석 및 시각화 시스템

## 🚀 주요 기능

### 📊 고급 재무 분석
- **계층적 재무 구조 분석**: 재무상태표, 손익계산서, 현금흐름표의 계층적 구조 시각화
- **연도별 성장률 분석**: 연도간 재무 항목 변화율 및 트렌드 분석
- **종속기업 관계 분석**: 삼성전자와 종속기업들 간의 투자, 거래, 채무 관계 분석
- **주석 및 문서 분석**: 재무 데이터와 연결된 주석 정보 검색 및 분석

### 📈 인터랙티브 시각화
- **계층적 구조 차트**: Sunburst 차트를 통한 재무제표 계층 구조 시각화
- **트렌드 분석 차트**: 연도별 재무 데이터 변화 추이 시각화
- **성장률 분석**: 막대 차트를 통한 성장률 비교 분석
- **네트워크 다이어그램**: 종속기업 관계 네트워크 시각화
- **섹션별 요약**: 파이 차트를 통한 재무제표 섹션별 비중 분석

### 🔍 지능형 검색
- **자연어 질의**: 한국어로 재무 데이터에 대한 질문 가능
- **의도 자동 감지**: 질문 유형을 자동으로 분석하여 적절한 분석 방법 선택
- **컨텍스트 기반 답변**: 재무 도메인 지식을 활용한 전문적인 답변 제공
- **질문 제안**: 자주 사용되는 질문 패턴 제안

## 🛠️ 설치 및 실행

### 1. 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. 환경 변수 설정
`local.env` 파일에 다음 정보를 설정하세요:
```env
NEO4J_URI=neo4j://localhost:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your_password
OPENAI_API_KEY=your_openai_api_key
```

### 3. 애플리케이션 실행
```bash
streamlit run streamlit_app.py
```

## 📊 지원하는 분석 유형

1. **계층적 분석**: 재무제표의 계층적 구조 분석
2. **카테고리 분석**: 카테고리별 재무 데이터 집계
3. **시계열 분석**: 연도별 변화 추이 분석
4. **성장률 분석**: 연도간 성장률 계산 및 비교
5. **관계 분석**: 기업간 관계 네트워크 분석
6. **주석 분석**: 재무 데이터와 연결된 주석 검색
